# Spotify Song Popularity Prediction

## Description
This project predicts whether a Spotify song is Popular, Moderately Popular, or Not Popular using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
songs_normalize.csv

## Model
Random Forest Classifier

## Accuracy
53.47%
